# セッションとプロジェクト

Kero は作業を 2 つの階層で整理します: プロジェクト（フォルダ）がセッション（タスク）をまとめ、すべてのセッションは閉じるまで kerod の中で動き続けます。

## セッション

**セッション**は作業の単位です: ひとつのタスク、ひとつのエージェント、ひとつの長時間動くプロセス。セッションには 1 つ以上の[ペイン](./panes.md)があり、それぞれでシェルかプログラムが動きます。

| アクション                     | ショートカット                                     |
| ------------------------------ | -------------------------------------------------- |
| 新規セッション                 | <kbd>⌘</kbd> <kbd>T</kbd>                          |
| ホームフォルダで新規セッション | <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>T</kbd>             |
| セッションへ移動…              | <kbd>⌘</kbd> <kbd>P</kbd>                          |
| 対応が必要なセッションへ移動   | <kbd>⌘</kbd> <kbd>J</kbd>                          |
| 次 / 前のセッション            | <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>]</kbd> / <kbd>[</kbd> |
| セッション名を変更             | <kbd>⌘</kbd> <kbd>R</kbd>                          |
| セッションを閉じる             | <kbd>⌘</kbd> <kbd>⇧</kbd> <kbd>W</kbd>             |

`fix-login-redirect` や `review-pr-42` のように、セッションにはタスクにちなんだ名前を付けましょう。サイドバーで見つけやすくなり、[CLI](./cli.md) から指定しやすくなります。

### 新規セッションの開始場所

`new-session-directory` 設定でフォルダを選びます:

- `current`（デフォルト）: 今いるセッションのディレクトリ
- `project`: プロジェクトのルートフォルダ
- `home`: ホームフォルダ

<a id="how-an-unnamed-session-is-named"></a>

### 名前のないセッションの名前

あなたかエージェントがセッションに名前を付けるまで、サイドバーに表示される名前は `session-name` 設定（設定の **セッション名の付け方**）で決まります:

- `focused`（デフォルト）: 今いるペインで動いているプログラムのタイトル。シェルだけが動いているペインは、最も対応が必要なペインに譲ります。
- `lead`: 最も対応が必要なペインで動いているプログラムのタイトル。作業中のエージェントや、あなたの対応を待っているエージェントなど
- `folder`: 何が動いているかにかかわらず、最初のペインのフォルダ

### 終了したセッション

設定 › 一般 › **セッション履歴**、または `session-history = true` でオンにします。

Claude Code、Codex、Pi、OpenCode が終了したとき、またはそのペインやセッションを閉じたとき、Kero は会話をあとで使えるよう、サイドバー下部の **終了済み** セクションに残します。見出しをクリックすると開きます:

- 終了済みには、エージェントのセッションが新しい順に、エージェント、名前、フォルダ、終了してからの時間とともに並びます。最新の 5 件のあとに **すべて表示** があります。Kero は最新の 50 件を残します。ほかのホストのものも、ホスト名のタグ付きで並びます。
- クリックすると、そのフォルダで新しいセッションが開き、`claude --resume <id>` や `codex resume <id>` と同じように会話を再開します。
- ポインタを重ねてアーカイブボタンをクリックすると、下の **アーカイブ** に移ります。そこからも再開できます。
- 右クリックすると、再開、アーカイブまたは復元、ID やフォルダのコピー、フォルダの表示、削除ができます。**終了済み** を右クリックするとすべてアーカイブ、**アーカイブ** を右クリックするとすべて削除できます。

これには、そのエージェント向けに [Kero のスキル](./agents.md#install-the-skill)をセットアップしておく必要があります。スキルが会話の ID を Kero に伝えます。

## プロジェクト

**プロジェクト**はフォルダです。Kero はサイドバーでセッションをプロジェクトの下にまとめます。<kbd>⌘</kbd> <kbd>O</kbd> で開くか、セッションの開始ディレクトリから `kero new` に選ばせます。

```sh
kero projects            # プロジェクトを一覧
kero new -p my-app       # 名前で指定したプロジェクトでセッションを開始
```

## kerod

セッションは、アプリが必要に応じて起動するデーモン **kerod** の中で動きます。Kero は kerod を映すウインドウです:

- Kero を終了しても、すべてのセッションは動き続けます。
- もう一度 Kero を開くと、スクロールバックも含め、すべてのセッションが元のまま表示されます。
- 再起動のあとなど kerod 自体が再起動すると、Kero はセッションをそれぞれのディレクトリで再び開始します。`restore-sessions = false` でオフにできます。
- そのエージェント向けに [Kero のスキル](./agents.md#install-the-skill)をセットアップしてあれば、Claude Code、Codex、Pi、OpenCode が動いていたペインは、エージェント自身の再開オプションと同じように会話を再開します。ほかのプログラムは勝手に再起動しません: そのペインはシェルに戻ります。`resume-agents = false` でオフにできます。

```sh
kero daemon status       # kerod は動いている？
kero daemon restart      # 再起動する（セッションは再び開始）
kero daemon stop         # 停止して、すべてのセッションを終える
```
